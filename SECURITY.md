# Security policy

## Reporting

Do not open public issues for vulnerabilities. Use GitHub private vulnerability
reporting on this repo's Security tab.

We will acknowledge your report within 72 hours. We will fix it or share a plan
within 14 days. We credit the reporter unless they decline.

## Scope

In scope: the till, the LNURL endpoints, the macaroon guard. Out of scope: LND
itself (report those bugs to LND), and misconfiguration such as
`--unsafe-allow-broad-macaroon`.

## Supported versions

The latest minor release.
