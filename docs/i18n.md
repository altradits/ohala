# Translating Ohala

Ohala is multi-language from day one. Every string in the UI comes from a
translation catalog. There is no help text, tours or tips in the UI; docs live
in the repo.

## How catalogs work

* Catalogs live in `locales/<bcp47>.json`. One flat file per locale.
  Keys map to strings, with ICU-lite placeholders like `{amount}`.
* `en.json` is the source catalog. Missing keys fall back to English.
* Locale order: the owner's choice in Settings, then the device's choice, then
  `Accept-Language`, then `en`.
* Plurals use objects like `{"one": "...", "other": "..."}`, resolved with
  `golang.org/x/text` (CLDR rules).
* Numbers and grouping come from `golang.org/x/text/message` per locale
  (1,000 vs 1.000 vs 1 000).
* The `dir` attribute follows the locale, and the CSS uses logical properties,
  so RTL locales (ar, fa, ur) work.
* The Settings picker shows only catalogs that are at least 90% translated.
  English fills any gaps.

## Glossary

Bitcoin terms stay consistent. Use the agreed word per language. Do not invent
a new word for these:

| Term | Meaning |
|---|---|
| sats | The unit. Lowercase, never translated. |
| BTC symbol | Shown as provided by the catalog for the locale. |
| Lightning | The network. Follows the agreed word per language. |
| invoice | The payment request. Follows the agreed word per language. |

Each language keeps its agreed words at the top of its catalog file or in its
translation issue. Translators for the same language agree there first.

## How to add a language

1. Copy `locales/en.json` to `locales/<tag>.json`, where `<tag>` is the
   BCP 47 tag (e.g. `sw`, `fr`, `pt`).
2. Translate every value. Keep the keys, the placeholders and the plural forms.
3. Run the catalog checker (`go run ./tools/i18ncheck`). It fails on unknown
   keys, mismatched placeholders, or missing plural forms. Missing keys are
   allowed (English fills them), but a new catalog should aim for 100%.
4. Open a PR using the translation issue form. A second speaker of the language
   must approve in review.

Launch catalogs: `en`, `sw` (Kiswahili). First community targets: `luo`
(Dholuo), `fr`, `pt`, `es`, `am`, `ha`, `yo`, `ar`.

## Human translators only

Translations must be your own work. No machine or AI translation. You must be
a speaker of the language you translate. There is no external translation
platform: it would be a third party.
